# WinSub

Subsonic/Navidrome desktop player for Windows XP–Win7 (32-bit)

## Features
- Multi-server support with profiles
- Sidebar navigation (Artists, Genres, Playlists, Favorites, Queue)
- Search across tracks, artists, albums
- AutoDJ auto-fill
- Drag & drop queue reordering
- Star/unstar tracks
- FFmpeg decoding for FLAC and Ogg Vorbis
- Media key support (play/pause/next/prev)
- Keyboard shortcuts (Space, arrows, Ctrl+F, F11)
- Cover art caching

## Requirements
- .NET Framework 4.0
- Windows XP SP3 – Windows 7 (32-bit)
- FFmpeg (for FLAC/Ogg Vorbis playback)

## Build
Open `SubsonicPlayer.sln` in Visual Studio 2019+ and build in Debug|AnyCPU.
